# GlycoRNADB V2 visual update

The first V2 revision applies FoldBridge's responsive header, capsule navigation, gradient surfaces, rounded cards, typography and spacing while preserving GlycoRNA's blue theme. Data, labels, figures, links, routes and existing API requests are unchanged.

Build locally with `npm ci` and `npm run dev`; create a static production build with `npm run build`. The V2 source retains the original hosting paths and external API endpoints; publishing from a new repository will not update the original production site automatically.

GitHub Pages preview: https://linyan-hu.github.io/GlycoRNADBV2/ .
